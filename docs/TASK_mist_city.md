## คอนเซ็ปต์ (1 ย่อหน้า)
เกมหลักเป็น 2D top-down สดใส — ผู้เล่นเจอ "ประตูวาร์ปร้าง" แล้วหลุดเข้า **เมืองซอมบี้มุมมอง side-view**
(เดินซ้าย-ขวา มี gravity/กระโดด) บรรยากาศหมอกพิษ เทา/เขียวหม่น/นีออน แบบ pixel-horror ไม่หนักเกิน
เข้าไปฟาร์ม "ชิ้นส่วน" (ต่างจากเหมืองที่ให้แร่) ภายใต้**เวลาจำกัด 5 นาที** พอหมดเวลาหมอกท่วม → เด้งกลับประตู
(ในเมืองมี **ตู้ยา 3 จุด** ฮีล 50% ใช้ได้จุดละครั้ง/รอบ; เพลงธีมเฉพาะ "mistcity" อยู่ใน audio.py แล้ว)
เอาของกลับมาขาย/คราฟต์/ส่งเควสต์ในโลกหลัก — คือ "เหมืองเวอร์ชันซอมบี้" ที่ replay ได้ทุกวัน

## กติกาเด็ดขาด
- **co-op 2 คนเต็มรูปแบบ** ตั้งแต่บรรทัดแรก: ทั้งคู่วาร์ปพร้อมกัน, กล้องตามสองคนแนวนอน,
  คนตาย = เป็นผีลอยรอที่จุดเกิด อีกคนเดินมาแตะเพื่อชุบ (หรือฟื้นเมื่อจบรอบ)
- โทนภาพต้องเข้ากับอาร์ต pastel เดิม (น่ากลัวแบบน่ารัก ไม่ gore)
- เมืองร้างให้ "ชิ้นส่วน" — ห้ามดรอปแร่ทับบทบาทเหมือง

## V1 scope (ทำแค่นี้ให้เสร็จก่อน)
1. **ไฟล์ใหม่ `src/mistcity/`** (Chat 7 เป็นเจ้าของคนเดียว):
   - `world2d.py` — แมพ side-scroll 1 โซน "ถนนกลางเมือง": เส้นพื้น + แพลตฟอร์ม (หลังคารถ/กันสาด),
     ฉากหน้าร้านพังๆ (ร้านยา/ร้านช่าง/ปั๊ม), ลังไม้/ถังแตกได้, ฉากหลังตึกเงาดำ+ไฟกะพริบ, หมอกพื้น
   - `player2d.py` — คอนโทรลเลอร์ platformer 2 ผู้เล่น: ซ้าย/ขวา + กระโดด (ปุ่ม up) + โจมตี (ปุ่ม action,
     ใช้ดาบ/tier เดิมจาก tool_tiers), HP/energy แชร์กับโลกหลัก, ระบบผี-ชุบตามกติกา co-op
   - `zombies.py` — ซอมบี้ 3 แบบ: walker (ช้า เลือดกลาง), runner (เร็ว เลือดน้อย), worker หมวกนิรภัย
     (เกราะ: ดาเมจที่โดนลด 30%) — สเตต/ดรอปกำหนดในไฟล์นี้ สเกลตาม "จำนวนรอบที่เคลียร์" ได้ภายหลัง
   - `mist_system.py` — `MistMixin`: enter/exit state `"mistcity"`, นาฬิกา 10:00 นับถอยหลังบน HUD,
     หมอกหนาขึ้นตามเวลา (overlay alpha), เวลา 0 → บังคับวาร์ปกลับ + ข้อความ "หมอกท่วมเมือง!"
2. **ดรอป 7 ชนิด** (ขอ Chat 1 ลงทะเบียนใน `loot.MATERIALS` → ได้ label/ราคาขาย/ขายที่ร้านฟรี):
   `scrap_iron` 25g, `wire` 30g, `old_coin` 35g, `gear_scrap` 45g, `old_battery` 60g,
   `mutant_herb` 80g, `tainted_crystal` 400g (แรร์ จากลังลับ/zombie หายาก)
3. **แหล่งของ**: ซอมบี้ดรอป + ลังแตกได้ (ตีด้วยดาบ) — ใช้ `loot.roll_drops` เดิม
4. **จุดเชื่อม (seams) ที่ต้อง "ขอ" แชทอื่น** (ห้ามแก้เอง):
   - Core (Chat 0): ค่าคงที่ `AREA_MIST="mistcity"` ใน settings + hook state ใน
     handle_events/update/draw แบบ **guarded** (`getattr(self,"_mist_update",None)`) + เรียก MistMixin เข้า Game
   - Chat 5 (World): ประตูวาร์ปร้าง (prop `mist_gate`) มุมลึกของป่า + warp เข้า/ออก
   - Chat 1 (Combat/Loot): เพิ่ม 7 ไอเทมเข้า `loot.MATERIALS`
   - เซฟ: V1 **ไม่ต้องเพิ่ม field** (ของติดกระเป๋า = เซฟอยู่แล้ว, รอบรีเซ็ตทุกครั้งที่เข้า)
5. **เสียง**: V1 ใช้เพลงเหมืองไปก่อน (theme หมอกค่อยขอ Chat 0 ทีหลัง)
