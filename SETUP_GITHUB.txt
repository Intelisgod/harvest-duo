  ระบบอัปเดตอัตโนมัติ (สำหรับคุณ - ผู้พัฒนา)
============================================================

ครั้งแรกครั้งเดียว:
  1. ดับเบิลคลิก  setup_github.bat
       - ถ้ายังไม่ล็อกอิน GitHub จะเปิดเบราว์เซอร์ให้กดยืนยัน
       - สร้าง repo สาธารณะ (โค้ดเกมเท่านั้น — รูป/วิดีโอ/เพลง/หน้าครบรอบ
         ไม่ขึ้นไปเด็ดขาด ตัวสคริปต์เช็กซ้ำก่อนส่งทุกครั้ง)
       - สร้างไฟล์  HarvestDuo_for_girlfriend.zip
  2. ส่ง zip นั้นให้แฟน "ครั้งเดียว" (มีรูป/หน้าครบรอบอยู่ข้างในแล้ว)
     แฟนแตกไฟล์ แล้วกด  "Play HarvestDuo.bat"

ทุกครั้งที่แก้เกม:
  - ดับเบิลคลิก  push_update.bat
       -> เทสเกมอัตโนมัติ (ไม่ผ่านจะถามก่อนส่ง)
       -> ส่งขึ้น GitHub
  - แฟนกดเล่นครั้งต่อไป = ได้เวอร์ชันใหม่เอง ไม่ต้องส่งไฟล์ใหม่

หมายเหตุ:
  - เซฟเกมอยู่ที่ %APPDATA%\HarvestDuo  อัปเดตทับยังไงเซฟก็ไม่หาย
  - ถ้าแก้ไฟล์ .bat / รูป / anniversary.html  อันนี้ไม่อัปเดตอัตโนมัติ
    (ต้องส่งให้แฟนเอง หรือสร้าง zip ใหม่:  py tools\release.py zip)
  - เล่น LAN ด้วยกันต้องเป็นเวอร์ชันเดียวกัน -> push ก่อนเล่น
