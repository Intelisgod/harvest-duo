==========================================
   HARVEST DUO  -  วิธีเล่น (สำหรับเพื่อน)
==========================================

ครั้งแรกครั้งเดียว:
  1. ติดตั้ง Python จาก  https://www.python.org/downloads/
     ** ตอนติดตั้งให้ติ๊กช่อง  "Add Python to PATH"  ด้วย **
  (มีแล้วข้ามได้เลย)

ทุกครั้งที่จะเล่น:
  >>> ดับเบิลคลิกไฟล์   "Play HarvestDuo.bat"   <<<
  มันจะ:
    - ลงสิ่งที่ต้องใช้ให้เอง (ครั้งแรก)
    - ดึงเวอร์ชันล่าสุดให้อัตโนมัติ (ถ้ามีเน็ต)
    - เปิดเกม
  ไม่ต้องโหลดไฟล์ใหม่เองอีกเลย เกมอัปเดตให้เอง

วิธีเล่นด้วยกัน (WiFi เดียวกัน):
  - เครื่องเจ้าของเกม: เมนู  ->  Online (LAN)  ->  Host Game
        (จะมีเลข IP ขึ้นมา เช่น 192.168.1.23)
  - เครื่องคุณ: เมนู  ->  Online (LAN)  ->  พิมพ์เลข IP นั้น  ->  Join Game
  - คุณคุมตัวละครด้วย  WASD + Space  (กล้องจะอยู่ที่ตัวคุณเอง)
  - เล่นแยกกันได้อิสระเหมือนเกมออนไลน์: ต่างคนต่างไปคนละแมพได้เลย
    (มุมขวา/ซ้ายล่างจะบอกว่าอีกคนอยู่แมพไหน)
  - จะนอนจบวันต้องกลับบ้านทั้งคู่ / Mist City ต้องไปที่ประตูในป่าพร้อมกัน

ติดปัญหาต่อไม่ได้?
  - ต้องอยู่ WiFi วงเดียวกัน
  - ครั้งแรกที่เจ้าของกด Host ให้กด "Allow" ตอน Windows ถาม Firewall
  - เจ้าของกับคุณต้องเป็นเวอร์ชันเดียวกัน (กด Play ให้มันอัปเดตก่อนเล่น)

ขอให้สนุกครับ!
